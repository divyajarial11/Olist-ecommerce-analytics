# Olist E-commerce Analytics

End-to-end e-commerce analytics project using SQL and Power BI to analyze sales, customers, product performance, delivery trends, and business KPIs.

## Tools
- SQL
- Power BI
- Excel / Power Query

## Project Goals
- Analyze revenue and order trends
- Understand customer behavior
- Identify top-performing products and sellers
- Evaluate delivery performance
- Explore the relationship between delivery delays and customer reviews
